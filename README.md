# Sistema Escola de Lutas Rafael Mota

Sistema administrativo e financeiro para gestão da academia.

## Stack
- Next.js 15 + React 19 + TypeScript
- Tailwind CSS
- Supabase (PostgreSQL, Auth, RLS e Storage)
- Vercel

## Papéis
- admin: administração completa
- teacher: acesso limitado às próprias turmas e alunos
- guardian: portal do aluno e responsável

## Princípios
- Segurança aplicada no banco por Row Level Security.
- Separação dos projetos Fundação Capoeira e Descarte Ideal.
- Histórico financeiro preservado e auditável.
- Interface responsiva.

## Estado
Fundação técnica inicial. Integração e schema Supabase serão implementados e testados em etapas seguintes.
